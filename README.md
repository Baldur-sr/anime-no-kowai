# ANIME NO KOWAI

Proyecto académico de Tecnologías de la Información. Sitio web temático sobre 6 animes de terror, suspenso y horror psicológico.

## Estructura

- `index.html`: página pública.
- `styles.css`: diseño oscuro, animaciones y responsive.
- `script.js`: consumo de Jikan API, búsqueda, modal y almacenamiento local.
- `admin.html`: login y panel de administración simulado.
- `assets/`: logotipo y material visual del proyecto.
- `GUIA_GITHUB_VS_CODE.md`: publicación desde VS Code usando Git y GitHub.

## Stack

HTML5, CSS3, JavaScript ES6, Bootstrap 5, Bootstrap Icons, Google Fonts y Jikan API.
